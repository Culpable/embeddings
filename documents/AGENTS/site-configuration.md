# Public facts

`src/config/site.ts` owns reviewed public identity, language, title separators, email and social-image facts. `src/config/canonical-origin.mjs` feeds Astro’s `site` setting and the Node compatibility helper. `src/lib/site-config.mjs` retains the reviewed route inventory used by metadata and discovery; it derives identity URLs from those shared owners.

Never add secrets, unverified addresses, business claims, ratings or profiles. Preserve the exact reviewed contact copy. A missing public postal address is a schema-completeness limitation, not permission to invent one. Inspect rendered public text, links, metadata, graph and discovery when a shared fact changes.
